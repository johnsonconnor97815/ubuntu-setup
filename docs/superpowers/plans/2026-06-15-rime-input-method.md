**Goal:** 新增 `scripts/rime.sh`——一个 fcitx5 + RIME 输入法的安装/配置组件管理器,curated 内置方案 + 雾凇拼音(rime-ice)可逆安装,配置收敛进受管文件,SSH/headless 诚实提示。

**Tech Stack:** bash、fcitx5/fcitx5-rime/im-config(apt)、RIME custom.yaml、systemd environment.d、git(rime-ice)。`lib/common.sh`/`lib/ui.sh` 原语。

### Task 2: 安装(核心 + best-effort 前端 + im-config + env.d + 基线配置)

**Files:** Modify `scripts/rime.sh`

- [ ] **Step 1: apt 候选探测助手 + SSH 提示助手**

```bash
_rime_apt_available() {
  local cand; cand="$(apt-cache policy "$1" 2>/dev/null | awk '/Candidate:/{print $2; exit}')"
  [[ -n "$cand" && "$cand" != "(none)" ]]
}
_rime_where_note() {
  if [[ -n "${SSH_CONNECTION:-}${SSH_TTY:-}${SSH_CLIENT:-}" ]]; then
    log_warn "This is an SSH session. RIME/fcitx5 is a desktop input method — these settings"
    log_warn "apply on a machine with a graphical session, not to this remote shell."
  fi
}
```

- [ ] **Step 2: env.d 受管文件写出(整写收敛 + backup)**

```bash
_rime_write_envd() {
  mkdir -p "$(dirname "$_R_ENVD")"
  local tmp; tmp="$(mktemp)"
  {
    printf '# Generated by ubuntu-setup (swkit rime). Do not edit; re-run swkit rime install.\n'
    printf 'GTK_IM_MODULE=fcitx\nQT_IM_MODULE=fcitx\nXMODIFIERS=@im=fcitx\n'
  } >"$tmp"
  if [[ -f "$_R_ENVD" ]] && cmp -s "$tmp" "$_R_ENVD"; then rm -f "$tmp"; return 0; fi
  backup_file "$_R_ENVD"; mv "$tmp" "$_R_ENVD"
}
```

- [ ] **Step 3: do_install()**

幂等闸:`status >/dev/null 2>&1 && { log_info 已装; return 0; }`(已装时仍 `_rime_resolve_home` 后确保 env.d/基线在位再返回——见下;或简单跳过并提示用 configure)。流程:
1. `_rime_resolve_home || return 1`
2. 核心:`apt_install fcitx5 fcitx5-rime fcitx5-config-qt im-config`
3. 前端 best-effort:`for p in fcitx5-frontend-gtk3 fcitx5-frontend-gtk4 fcitx5-frontend-qt5; do _rime_apt_available "$p" && apt_install "$p" || log_warn "skip $p"; done`
4. 框架:`im-config -n fcitx5 >/dev/null 2>&1 || log_warn "im-config -n fcitx5 failed"`(用户态)
5. `_rime_write_envd`
6. `_rime_load; mkdir -p "$_R_RIME_DIR"; _rime_write_default_yaml`(Task 3 定义)
7. 提示:重新登录使 env.d 生效 + `_rime_where_note` + 指向 `swkit rime configure`。

### Task 3: configure + 受管 default.custom.yaml + 方案动作

**Files:** Modify `scripts/rime.sh`

- [ ] **Step 1: 受管 default.custom.yaml 写出**

```bash
_rime_write_default_yaml() {
  mkdir -p "$_R_RIME_DIR"
  local f="$_R_RIME_DIR/default.custom.yaml" tmp; tmp="$(mktemp)"
  {
    printf '# Generated by ubuntu-setup (swkit rime). Do not edit; re-run swkit rime configure.\n'
    printf 'patch:\n'
    if [[ "${RIME_ICE:-0}" != 1 ]]; then
      printf '  schema_list:\n'
      local s; for s in $SCHEMAS; do printf '    - schema: %s\n' "$s"; done
    fi
    printf '  "menu/page_size": %s\n' "$PAGE_SIZE"
  } >"$tmp"
  if [[ -f "$f" ]] && cmp -s "$tmp" "$f"; then rm -f "$tmp"; return 0; fi
  backup_file "$f"; mv "$tmp" "$f"
}
```

```bash
_rime_deploy() {
  if [[ -n "${SSH_CONNECTION:-}${SSH_TTY:-}${SSH_CLIENT:-}" ]] || [[ -z "${WAYLAND_DISPLAY:-}${DISPLAY:-}" ]]; then
    log_info "No graphical session here — deploy where the desktop runs (fcitx5 tray ▸ Deploy), or it applies on next login."
    _rime_where_note; return 0
  fi
  if have_cmd fcitx5-remote && fcitx5-remote -r 2>/dev/null; then
    log_info "Asked fcitx5 to reload/redeploy RIME."
  else
    log_info "Could not reach a running fcitx5 — deploy via the tray (▸ Deploy) or re-login."
  fi
}
do_deploy() { _rime_resolve_home || return 1; _rime_deploy; }
```
