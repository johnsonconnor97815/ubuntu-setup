# 明确目录的数据迁移

`scripts/storage_move.py` 用于已经授权的目录迁移。它复制到指定挂载盘，在原路径保留软链接，完成功能检查后才删除旧目录。它不是自动清理程序，不负责选择数据、修改应用环境变量、停止应用或配置系统服务；执行者必须先核对这些条件。

需要 Linux 的 `renameat2(RENAME_EXCHANGE)`、Python 3.10+、支持 ACL/xattr 的 rsync，以及已挂载且支持原权限、软链接和稀疏文件的目标文件系统。普通操作使用当前用户；确需保留其他属主或修改受保护目录时，以 `--privileged` 明确选择逐命令调用仓库的 `sudo_run`，不整体以 root 运行。源文件、执行记录、备份和真实机器路径不提交到仓库。

## 执行流程

先检查目标挂载、空间和相关进程，确认应用允许短暂中断。记录目录使用仓库之外的私有位置。下面路径均为占位符：

```sh
python3 scripts/storage_move.py prepare /private/run/item.json /source/directory /mounted-disk/data/directory /mounted-disk
python3 scripts/storage_move.py copy /private/run/item.json
python3 scripts/storage_move.py switch /private/run/item.json
python3 scripts/storage_move.py check /private/run/item.json /path/to/application --version
python3 scripts/storage_move.py finish /private/run/item.json
```

- `prepare` 拒绝已存在的记录和目标目录、路径重叠及未挂载目标，记录源 inode、设备号和目标设备号。
- `copy` 通过 rsync 保留权限、属主、时间、软链接、目录内硬链接、ACL/xattr 和稀疏文件。目标为本次新建的专用目录；续传会同步更新或移除该暂存目录中已不属于源目录的文件。复制完成本身不代表校验通过。
- `switch` 用 rsync 全文件校验和与元数据比对确认副本，拒绝观察到的可写文件描述符，原子交换源目录和兼容软链接，再复核目录身份与入口。旧副本保留在源目录旁的 `.原名.storage-move-记录名`。遍历 `/proc` 受当前权限限制，应用停写与资源协调仍由执行者保证，不能把描述符检查当作全系统锁。
- `check` 执行并记录一条应用检查命令。应选择能证明迁移后路径可用的命令，并按需要补充实际读写、构建、模型推理等检查；退出码 0 或 `--version` 不能证明全部功能正常。记录仅应包含必要且无秘密的命令与输出。
- `finish` 要求已有成功检查，重新校验旧副本中的内容与元数据，允许目标新增文件和目录时间变化，刷写目标文件系统，然后只删除 inode 匹配的旧目录。目标、兼容链接、校验或旧目录身份不匹配时保留原数据。旧副本内出现其他挂载时拒绝删除。

不要对正在使用的数据库、虚拟机磁盘或下载文件直接执行。用户备份可能包含私有配置和凭证，目标父目录必须维持原有保护。跨迁移条目的硬链接不自动合并；移除旧副本后以文件系统实测释放量为准。

## 中断、失败与恢复

每条命令的日志、退出码和阶段记录都保存在记录文件旁。复制中断后，先确认旧进程已退出、目录身份和应用状态未变，再对同一记录重跑 `copy`。记录文件锁不能阻止其他程序写入源数据。

切换或清理中断时必须先检查源路径、软链接和旧目录现场。已完成交换但未记录完成的切换可以重新运行 `switch` 复核；交换前留下的临时链接、创建目标后未记录 inode，以及旧副本已经删除但阶段尚未保存的情况，需人工核对，脚本不会猜测成功。`finish` 的删除中断可以在现场核对后继续，但若路径已经消失则必须检查实际目标和日志。

旧副本尚在且两边没有后续变更时，可以核对记录中的源 inode、目标身份后反向执行原子交换，恢复原目录；交换后留下的临时软链接应单独核对并移除。目标已有新数据时，不直接换回旧副本。旧副本已删除后只能从新位置反向复制并重新验证，不能承诺立即回滚。

`mount_guard()` 可以生成服务依赖数据盘的 systemd `[Unit]` 片段，包含挂载依赖、挂载点条件及解绑时停止服务的依赖。它只生成文本，执行者仍需核对本机 systemd 版本、现有服务配置、目录访问权限，校验候选内容后再安装独立 drop-in 并验证实际生效状态。脚本不会自行修改 fstab、全局环境或已有服务配置。

## 验证

```sh
python3 -m unittest discover -s tests -p test_storage_move.py -v
git diff --check
```

测试在临时目录验证复制、兼容入口、原数据保留、功能检查闸门、活动写入和路径身份变化。它们不覆盖真实 USB 断连、突然断电、所有文件系统及实际应用兼容性；真实迁移仍需记录目标环境和功能验证范围。
